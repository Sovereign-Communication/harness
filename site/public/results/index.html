What changed in this batch

  • #339 answered the efficiency question with live evidence: a cheaper apply model was selected, pay-per-token caching was measured, and the run stayed inside the authorized budget. The result was a verified efficiency receipt, not a claim of an arbitrary speedup.
  • #330 made the dogfood verification phase reachable from the CLI by accepting and forwarding cancel_check; a contract test pins the forwarding so the phase cannot silently disappear again.
  • #347 fixed config/Jev precedence: when Jev is disabled, the provider preview now stops before transport instead of issuing a paid call, and malformed override values are ignored rather than revived.
  • #327 decoupled gate execution from the caller's working directory: gate argv and paths resolve from the repo root, a missing route target is a loud refusal, and a foreign-CWD compileall is proven to compile the real tree.
  • #278 unified external-tool resolution and added strict preflight. HARNESS_PYTHON and HARNESS_RUFF are honored, a python3-only environment works, and apply refuses before spending when a tool is missing.
  • #276 made D12 measure the runtime merge-base instead of a stored baseline SHA. Current-tree coverage is regenerated when the fast-path document does not name that base; the real-diff proof is 1/1 = 100% with a 0/1 = 0% negative control. S5 now names the shared ruff resolver, and the triage runbook records the missing-tool signature.
  • #331 stopped a fail-open D12 SKIP from earning measurement credit. The table prints skip, the receipt writes status=skip with a null score, and dimension means/Jev evidence count only measured rows; an all-skip dimension is not_evaluated, never a pass.
  • #333 made task-ID validity ledger-backed: offers establish IDs, all non-offer task-bound writes reject unknown IDs without ledger rows, and external IDs are preflighted before provider calls. Generated IDs are recorded before use, with a Windows short-path regression pinned through the CLI.
  • #279 added a read-only harness doctor preflight. It reports tool and key presence, DNS/TypeSafe reachability, driver health, GUI state, ledger writability, and a real MCP stdio smoke with safe JSON output; 34 focused tests and the full 5,144-test suite passed, and PR-head/main CI passed D12.
  • #287 preserves per-ref cancellation and skips the five-platform matrix only for docs/site-only diffs; missing or failed change detection keeps the full matrix, while audit and the other required checks remain active.
