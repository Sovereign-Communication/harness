Publish your evidence

  1. Run harness site-export --ledger <ledger.jsonl> --consent <consent.json> --yes --out bundle.json on your machine.
  2. Paste or load the bundle below. The page renders exactly what will be sent — the same sanitized fields anyone will see.
  3. Confirm the consent checkbox and submit. The server re-validates the schema, the consent block, and the bundle hash before accepting.

What a bundle can and cannot contain

Cannot: prompt text, file paths, gate output, error text, caller identity, task names (hashes only). Can: model ids, tiers, costs, outcomes, round counts, escalation provenance. The full allowlist is in harness/site_export.py.

Deletion: open a repo issue referencing your bundle_id; removal propagates at the next aggregate rebuild.
