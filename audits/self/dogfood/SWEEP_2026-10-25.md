## Findings and disposition

1. **Fixed — `apply` / `continue` had no `--max-cost`.** `apply --max-cost 0.5`
   died in argparse; only the env var could cap a local apply. The flag now
   lives in the shared engine-flag helper (dogfood and plan opt out because they
   declare their own variant), both handlers pass it to the session governor,
   and a real `apply --max-cost 0.0000001` run refuses at preflight with the
   ceiling error instead of a parser error. Tests:
   `tests/test_dogfood.py::ApplySessionCeilingCliTests`.

2. **Fixed — `dogfood --max-cost` did not reach the apply phase.** The verify
   phase honoured the flag; `service.run_dogfood` then built the apply session
   with `session_caller(settings)`, so a `--max-cost 0.5` run stopped at the
   configured `$0.02` at apply (`worst-case estimate $0.022981 exceeds
   remaining ceiling $0.020000`). The run's ceiling is now forwarded
   (`session_caller(settings, max_cost)`), the HTTP and MCP dogfood seams accept
   the override, and the same live run now completes all three phases. Test:
   `tests/test_dogfood.py::DogfoodVerifySeamContractTests::test_run_dogfood_passes_max_cost_to_apply_session`.

3. **Observed, not changed — live JEV holistic label vs the bar.** JEV-P1's
   live judgment scores 84.17 and labels the phase `fail`, while no sentiment
   axis is blocking and every hard gate passes, so `can_mark_complete` is true
   (combined 95.25). This matches the ratified v1 policy ("gate on risk, not on
   numbers"; only actual risk blocks) and the pack's `primary_gap: none`; the
   holistic label is advisory. Recorded rather than "fixed", because changing it
   would mark shipped pages incomplete without a risk finding.

4. **Resolved — budgets now make the shipped bench path run and the apply
   refusal discoverable.** A fresh ledger makes the trust gate step a free
   primary to the cheapest paid rung (`openai/gpt-5.6-sol`), whose three-slot
   worst case is ~$0.168; the default apply task ceiling is $0.10 and the
   session ceiling is lower still, so it refuses before spending. The fix is
   explicit and does not touch the global ceiling: all nine bundled fixtures
   now pin `task_max_cost: 0.25`, bench gained `--task-max-cost` for manifests
   that do not pin their own, and README documents both the funded bench
   invocation (`--max-cost 0.5`) and the apply refusal with the exact
   `--task-max-cost 0.5 --max-cost 0.5` unblock. Receipts: default bench exits
   2 at the session ceiling; funded bench exits 0 with 9/9 passing; default
   apply exits 1 at preflight; funded apply exits 0. The refusals stay explicit
   and fail-closed — only the fixtures' own budgets and the documented flags
   changed.

5. **Environment note — learned-BYOK pool filter.** Live runs log
   `deepseek/…, google/gemini-3.8-flash, deepseek/deepseek-v4.1-flash skipped:
   learned-BYOK org filter (paid route)`, leaving ling as the responding
   panelist. This is the operator's learned-BYOK state, not a code defect; the
   run remains honest (`panel_failures` records `pool_filtered`).

6. **Open by design.** `EV-8` (live Fireworks probe needs the operator's paid
   key) and `OC-HANDOFF` (experimental OpenClaw lane) are the only phases the
   local jev sweep cannot mark complete; both are already open/deferred in
   canon. No other phase is open.
