# OpenClaw dogfood operations

The AWS instance owns deterministic queue processing. Idle queue checks do not call a model.
Only an approved single-file task manifest can reach the worker.
SparkX generates one bounded candidate; Harness owns the edit and prescribed verification.
Native Jev completion requirement: pending live verification.
Completed local verification, committed artifacts, and SCM delivery are separate states.
Only the operator's Pixel Android identity can submit commands or receive completion reports.
Interrupted edits and ambiguous message sends require review rather than automatic replay.
The GPT subscription is reserved for planning and exceptional independent review.
An encrypted off-instance state backup is kept under the operator's SSH directory.
AWS snapshot, termination-protection and volume-expansion permissions are currently denied.
The separate SCM cloud node must remain untouched by OpenClaw maintenance.
