## Spec ambiguity - blocks implementation

The issue requires opt-in to be revocable while forbidding user-attributable contribution data. It does not say whether revocation applies only to future ingestion or must also retract a contribution already included in a published aggregate. Those requirements imply different data and retention designs. This decision must be answered before implementation; no guess or attributable contribution log is introduced.
