# Issue #279 — `harness doctor`

## Scope

Implement the requested environment preflight through the real CLI. The report
covers Python and Ruff resolution, OpenRouter key source and spend limit, Jev
key presence, TypeSafe endpoint reachability, DNS address class, driver health,
GUI port state, ledger writability, and a real MCP stdio initialize/list/read
smoke. JSON output contains safe metadata only; credential values are not
included. A missing check exits 1; degraded reachability remains a warning.

## Implementation

- Added `harness doctor [--json] [--gui-port PORT]` with a human report by
  default and a structured JSON report on request.
- Added a source-aware OpenRouter key resolver that preserves the existing
  `resolve_api_key()` behavior while returning only file/environment metadata.
- External credential probes are bounded, make no model-inference calls, and
  are skipped when DNS resolves to non-public addresses. The fake-IP regression
  confirms that the provider key probe is not sent in that case.
- The MCP check launches the current resolved Python through `harness.osal`,
  performs initialize, `tools/list`, and `ledger_status`, and keeps auth data in
  the child’s stdin frame only.
- Added the public module to the `CONTRIBUTING.md` ownership map.
