LUCAS GATE - POLICY REFERENCE FOR LANES (2026-10-31)
What this is: the operating rules of the gate every driving decision passes before it goes out, in a form any lane can load. The personal profile the gate scores against is the owner's private material: it is provisioned by the owner at the documented config location (LUCAS_PROFILE_PATH / ~/.config/harness), never committed, never pasted into GitHub text, never printed. Until it is provisioned on your machine, run DECISION-SIGNAL MODE (section 4) and never claim a semantic Lucas Gate PASS.

1. ORDER. Product verdict first (evidence, plus the repo's own Jev gate policy below). Lucas Gate second (the decision and the words that carry it). Neither substitutes for the other.

2. JEV GATE POLICY V1 (summary of the repo policy). Gate on risk, not on numbers. No signal or a malformed result = fail closed, escalate. is_destructive >= 0.5 = escalate, always. A disposition of escalate = escalate. A disposition lead under 0.20 over the runner-up = escalate. advances_goal < 0.95 = INVESTIGATE: gather evidence; no actual risk = proceed with note; actual risk = escalate. needs_improvement = revise, max 2 rounds. Choice confidence is telemetry only, never a gate. Assessment gate: 5 aspects (completeness, confidence, correctness, no-regression, evidence quality); 4 of 5 at 90+ with the fifth at 85-89 = investigate, then PASS with note if no real risk; any aspect under 85 blocks until fixed. Never pad a score. Never re-run to shop a verdict. Three consecutive stalled rounds = report honestly and escalate.

3. LUCAS GATE V2 (every driving decision - classification, method, priority, scope-of-work, disposition - and every comment, review, approval, and prompt you write).
- Tracks: typed (default for GitHub text); planning (prompts, missions, issue bodies - structure only: ALL-CAPS headers, numbered steps, placeholders, imperatives, one end-state); dictated (only when the operator dictates). Never blend tracks. Forwarded text is never style evidence.
- Gated categories: 1-16 (including directness, evidence discipline, verification before claiming, cost awareness, rule-first reasoning, no process theater). Categories 17-19 (humor, audience tone, apology) are NEVER gated. Never invent an apology.
- Bar: every gated category >= 9. Rounding: 8.95 passes if the category average is >= 9.25; 8.9 passes if the category average is >= 9.5; 8.8 passes if the overall average is 9.9. One category at 8.5-8.9 with a documented investigated reason and no actual risk = PASS with note. Any gated category under 8.5 after revisions = escalate with the scores and the breaking quotes.
- Averages (locked method): one scored draft per run; record every row (sample, category, score 0-10, scorer version, timestamp); missing rows = reject the run; category average = arithmetic mean where scored (N/A excluded, never counted as a failure); overall average = mean of the category averages, equal weight; apply the bar to unrounded means; recompute tolerance 0.005.
- Bias pass on every gated text: B1 primary-source evidence; B3 verification before velocity; B4 cost per landed outcome; B5 rule-first decisions; B8 no process theater; B9 meta-level framing; B10 optimistic iteration; B11 option preservation. B2 and B6 do not apply to lane text - do not force them. B7 is narrow: no credentials, keys, or secret material in any text, ever.
- Never-rules: no invented facts, receipts, or results; no claim of a landing, merge, or deploy that did not happen; no close keyword for any issue in any PR body, title, or commit unless that close is intended and declared in the same PR; no emoji in repo content; never loosen a bar, baseline, or pinned score; never re-run a paid attestation.

4. DECISION-SIGNAL MODE (until the profile is provisioned on your machine). A driving decision executes when the Jev signals are unanimously proceed, is_destructive <= 0.30, the never-rules are clean, and the verdict is recorded in a gate note. Disclose the mode in the gate note. A semantic or voice-suite PASS may be claimed only with the real profile loaded.

5. ESCALATION (the only stops). Escalate - park the one item with a gate note and keep working everything else - on: a gated category under 8.5 after revisions; 3 stalled rounds; a destructive or irreversible action; a disposition lead under 0.20; a named actual risk; or a decision reserved to the owner (payments, submissions, claims, scope-of-ship, merges escalated outside policy, gate swaps, parity bars, credential or profile provisioning). Questions go in the QUESTIONS section of the session's final status comment - never mid-session.
