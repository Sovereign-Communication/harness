# Issue #287 — CI scheduling

**Status:** initial PR run queued; cancellation probe in progress.

## Specification

- Cancel superseded runs for the same ref.
- Docs/site-only changes skip the five-platform hermetic test matrix while audit and other required checks remain enabled.
- Non-doc/site changes continue to run the full matrix and every existing check.
- Verify both change classes and cancellation through GitHub workflow runs.

The issue thread repeats these requirements. Its scope is clear.

## Baseline inspection

- `.github/workflows/ci.yml` already defines a per-ref concurrency group with `cancel-in-progress: true`; this behavior will be preserved and verified with consecutive pushes to the same PR.
- The workflow currently has five hermetic matrix jobs plus independent audit, package, and checkout-hygiene jobs; it has no path classification.
- Path filtering will be job-level. The workflow itself remains enabled for every event, so a docs-only change cannot leave a required workflow check pending. If change detection cannot identify the base or diff, the hermetic matrix runs.

## Implementation

`.github/workflows/ci.yml` keeps the existing workflow-level, per-ref
`cancel-in-progress: true` concurrency rule. A new `changes` job classifies the
base-to-head diff and sets the matrix output. Only `docs/**`, `site/**`, and
Markdown-only diffs skip the hermetic matrix. Unknown bases, empty diffs,
manual dispatches, and change-detection failures all retain the full matrix.
The workflow itself stays unfiltered; audit, package, and checkout-hygiene
jobs remain independent. A skipped matrix job is accepted as a successful
required check by GitHub; the workflow and audit still run for docs-only PRs.

## Cancellation probe finding

The first PR run started all five matrix jobs. After a follow-up push, the
older run remained active while the new run queued. The matrix condition used
`always()`, which GitHub documents can keep work running after cancellation.
The condition is now `!cancelled()` while still running the matrix if the path
detector fails. The queued run was manually canceled for cleanup; a fresh
same-ref cancellation probe is pending.
