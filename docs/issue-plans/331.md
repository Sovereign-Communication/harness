# #331 — D12 SKIP is a skip, not a pass

**Status:** complete on `main` (`52f51b9`, PR #371).

## Problem

The fail-open local D12 path returns score `1.0` with `SKIP (fail-open): ...`
evidence. PR #352 fixed the audit table label, but the JSON receipt still
recorded `score: 1.0`, and every dimension mean, satisfied-count and Jev
evidence block still counted the skipped check as measured. A table-only
reader saw `skip`; a JSON or aggregate reader still saw a pass.

## What changed

- `audits/self/audit.py` has one status owner (`_status`): `pass`, `part`,
  `FAIL` or `skip`. The table and the receipt use the same value.
- Each `round2_scores.json` row now carries `status`; a skipped row carries
  `"status": "skip"` and `"score": null`, and the receipt records
  `"skipped_checks": {"SD": ["D12"]}`.
- Dimension means, the satisfied-count and Jev dimension evidence are
  computed over measured rows only. A skip contributes to neither numerator
  nor denominator.
- A dimension where every check skipped is omitted from Jev evidence and
  prints `[N/E]`; it cannot become a pass.
- Fail-open locally and fail-closed in CI are unchanged.
